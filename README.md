# Структура приложения в FigJam

Скилл для Codex: собрать структуру приложения из обсуждений и спецификаций, привести в порядок разделы и переходы, написать понятные подписи для блок-схем.

## Особенности

- Учитывает последние решения пользователя и не повторяет уже закрытые вопросы
- Различает подтверждённые требования, предложения и неизвестное поведение
- Выстраивает иерархию разделов и сохраняет дополнительные точки входа
- Проверяет стрелки, возвраты, ссылки и цели после копирования доски
- Помогает подготовить структуру для варфов без лишней детализации
- Пишет коротко и просто, иногда со строчной буквы, без длинных тире и средних точек
- Использует обычные двойные кавычки, "СМС", "гемы", "звёзды", "тг" и "мини-апп"

Стиль действует на видимые подписи. Он не меняет ID, URL, код или точные цитаты. Примеры не задают продуктовые требования.

## Установка

```bash
npx skills add https://github.com/diqsi123/tester3223 --skill figjam-product-structure
```

Можно также скопировать папку `skills/figjam-product-structure` в каталог скиллов своего агента.

## Использование

```text
Используй $figjam-product-structure
Проверь структуру и связи в этой доске, учти последние решения из переписки
Подписи сократи и напиши в нашем рабочем стиле
```

Для объяснения без изменений:

```text
Используй $figjam-product-structure
Пока без правок на доске: объясни комментарий и предложи понятный текст
```

Для изменения доски нужен доступ к Figma. При использовании `use_figma` агенту также нужен установленный скилл `figma-use`. Без доступа можно подготовить тексты, вопросы и план изменений.
